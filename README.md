# 游戏汉化公开发布库
这里逐步提供汉化源码、补丁、对应最终版本的真实截图、版本说明及公开反馈记录。当前各条目的公开资产是否齐全，以各游戏页面为准；已列入索引不等于已经公开发布全部资料。

- [原输入ROM完整SHA256清单（134款）](data/original-input-hashes.csv)；改版、地区和修订身份沿用实际原输入名称。
- [版本索引](data/versions.json)。
- [哈利波特与魔法石](games/harry-potter-stone/README.md) · [哈利波特与密室](games/harry-potter-chamber/README.md)。
- [报告BUG](https://github.com/shiyi1133/youxi-hanhua-releases/issues/new?template=bug_report.md) · [公开反馈说明](feedback/README.md)。

本库不提供游戏ROM、存档、即时状态或私人会话。补丁须应用于清单中SHA256一致的实际原输入；普通字、大字和音频变体分别核对版本与目标SHA。测试版、受控测试、自然流程、实机和全通验收分别说明；问题单开放只表示尚未关闭。
