# 公开反馈与BUG入口

[报告BUG](https://github.com/shiyi1133/youxi-hanhua-releases/issues/new?template=bug_report.md)。请写游戏名称、实际版本／字号／音频变体、必要步骤和已有截图；不要上传ROM、存档、即时状态、凭据或私人聊天。

本次整理 453 条有公开帖子定位的证据摘录、125 个关联反馈范围及 100 个按原问题单去重的问题记录。另有缺少公开证据或游戏定位的信息保持待核，不向这里搬运私有正文。

- [问题状态索引](problems.json)；明确归类的开放纯BUG 29 项，建议等 9 项，分类待核 41 项，分别计数。
- [反馈范围](cases.json) · [公开原话摘录](public-quotes.json)。

开放不等于正在修复，关闭不自动代表全部症状或完整游戏已验收。实际玩家ROM SHA未知时保持未知，不能用当前发布目标SHA冒充。公开Issue尚待单独审核建立，这些记录不宣称已创建公开Issue。
